# Amazon Sales Analysis

## 📊 Project Overview

Amazon Sales Analysis is an end-to-end data analytics project focused on analyzing sales performance, product categories, regions, payment methods, order status, and profit margins.

The project combines Python-based data analysis with an interactive Power BI dashboard to transform raw sales data into meaningful business insights.

## 🎯 Project Objectives

- Analyze overall sales performance
- Understand sales distribution across product categories
- Compare sales performance across regions
- Analyze different payment methods
- Examine order status distribution
- Identify top-performing products
- Analyze profit margin across product categories
- Create an interactive Power BI dashboard
- Generate data-driven business insights

## 🛠️ Tools & Technologies

- Python
- Google Colab

- Seaborn
- Microsoft Power BI

## 📁 Dataset

The project uses the Amazon Sales Dataset containing sales and order-related information.

Key fields analyzed include:

- Region

- Quantity Sold
- Discount (%)
- Profit Margin
- Payment Method
- Order Status
